# 途记 · 旅行攻略

手机浏览器打开即用的旅行规划 App（PWA），完全免费，数据只存在你自己的设备上。

## 功能

| 模块 | 说明 |
|---|---|
| 行程 | 按国家 → 城市建旅行，卡片式首页，倒计时 |
| 城市地点 | 搜索 / 批量粘贴地名 / 粘贴 Google Maps 链接 / 地图点选；住宿、景点、餐厅分类 |
| 智能路线 | 按出发时间、营业时间、起终点自动排出最顺的顺序（不走回头路）；一键把城市地点分到每天；导出到 Google Maps 导航 |
| 交通 | 机票/车票录入，按酒店到机场的车程自动算出几点出发；导出日历提醒（.ics） |
| 天气穿衣 | 16 天内实时预报，更远用往年同期平均；按温度/降雨/紫外线/寺庙/海滩推荐穿衣 |
| 行李清单 | 按天气 + 目的地 + 航班自动生成，可勾选、返程模式、存模板 |
| 钱包 | 汇率换算 + 记账（自动折算人民币） |
| 足迹地图 | 完成的旅行自动点亮国家和城市，可手动补录，导出分享图 |
| 证件 & 分享 | 护照有效期提醒、酒店确认号、「给司机看」全屏地址卡、只读分享链接、备份导入导出 |

## 本地开发

```bash
npm install
npm run dev
```

## 部署到 GitHub Pages（免费）

1. 在 GitHub 新建一个 **Public** 仓库（例如 `tripnote`），不要勾选添加 README。
2. 仓库 → Settings → Pages → Build and deployment → Source 选 **GitHub Actions**。
3. 把本文件夹推送到仓库的 `main` 分支，Actions 会自动构建并发布。
4. 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`。

手机上用 Safari / Chrome 打开链接 → 「添加到主屏幕」，之后像 App 一样使用。

## 用到的免费服务

地图 OpenStreetMap · 地点搜索 Nominatim · 路线 Valhalla / OSRM（FOSSGIS）· 天气 Open-Meteo · 汇率 ExchangeRate-API。全部无需注册、无需 API Key。
